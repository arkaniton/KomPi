# Продукт и структура

КомПИ+ обслуживает бизнес и частных клиентов; аудитории одинаково важны. Вход без обязательного выбора «бизнес / частный клиент»: начинаем с задачи посетителя. Четыре направления по подтверждённому ТЗ: кассовое и торговое оборудование, ремонт компьютеров и периферии, 1С, картриджи. Для бизнеса предусмотрен отдельный маршрут комплексного обслуживания. Все работы из ТЗ актуальны; детализацию добавлять постепенно.

Сценарии: выбрать направление → обратиться; обслуживание бизнеса → обсудить задачу; покупка товара → действующая витрина mag1c; неизвестная проблема → связаться с человеком. Магазин https://kompi.mag1c.ru уже работает, заказы отправляются в 1С; не заменять и не нарушать обмен. Заявки на услуги предполагается направлять в будущий Telegram-бот с распределением сотрудникам; телефон и сайт остаются альтернативами.

Работы учитываются в 1С в документах сервисного центра. Возможности получения статусов и подключения неизвестны: не обещать их до технической проверки. Сначала — демонстрация, затем подтверждение содержания и работоспособная форма, уведомления и эксплуатационная инфраструктура. Не хранить личные данные клиентов в репозитории.
