# Эксперимент: карточка после перезапуска

Дата: 20.11.2026. Код в `experiments/` — исследовательский прототип **только для вымышленных данных**, не бэкенд проекта и не готовая система обработки персональных данных.

## Что проверяли

Временная SQLite-база хранится отдельно от кода. Вымышленная заявка создаётся, после чего первый процесс Claude получает сообщение о двух картриджах TestCart T-100 и записывает извлечённые поля. Процесс завершается. Второй независимый процесс открывает ту же базу, получает исправление: картридж один, и обновляет количество. Затем третий шаг считывает карточку и журнал изменений. В конце база удаляется.

В результате модель и способ передачи сохранились, количество обновилось с 2 до 1, история содержит обе записи. Каждый факт сопровождается цитатой клиента. Наличие цитаты не доказывает, что значение интерпретировано верно.

Дополнительно запускались шесть автоматических проверок на вымышленных данных:

1. Восстановление карточки в новом процессе и сохранение истории исправлений.
2. Изоляция двух искусственных идентификаторов клиентов на уровне функции чтения и записи.
3. Отклонение недопустимого изменения прайса вместе со всей заявленной операцией.
4. Отклонение отсутствующей цитаты и явно неизвестного значения.
5. Отклонение сохранения с устаревшей версией карточки.
6. Повтор события без дублирования и отказ при повторном использовании идентификатора для другого содержания.

Команда: `PYTHONDONTWRITEBYTECODE=1 python3 experiments/test_synthetic_store.py`. Все шесть проверок прошли. Процессный эксперимент с Claude также завершился успешно, вызвав модель дважды.

Расчётная стоимость по базовым ценам до 100k входных токенов ($0.10 и $0.50 за миллион входных и выходных соответственно) — около $0.0003021. Фактическое списание в аккаунте не проверялось. Источник цен: https://platform.claude.com/docs/en/about-claude/pricing

## Ограничения

- Все тесты проведены на фиктивных обращениях. SQLite здесь — временная база на время теста, которая действительно переживает перезапуск отдельных процессов, но в конце полностью удаляется. Это не продакшен-хранение, бэкапы или высокая доступность.
- Идентификатор клиента — тестовая строка, которую программа получает от теста; никакой настоящей аутентификации Telegram здесь нет. Прохождение теста изоляции не доказывает безопасность реального доступа.
- Прайс, полномочия сотрудников, директор, уведомления, 1С, согласия и клиентская переписка не интегрированы. Для реального запуска необходимы политика данных, правовой анализ, защищённое размещение, ограничение доступа, хранение и удаление, шифрование, резервное копирование и отдельные испытания.
- Тест с Claude охватывает одну короткую вымышленную заявку в двух сообщениях; устойчивость к неоднозначным фразам, отрицаниям и подмене инструкций не доказана. Точная цитата — проверка происхождения, а не проверка смысла.
- В журнале прототипа сохраняются полные тестовые сообщения. С реальными данными состав журнала, сроки и право доступа должны быть определены отдельно. Публичный GitHub не используется для реальной памяти, заявок или ключей.
