# КомПИ+

Проект корпоративного сайта сервисной компании в Томске. Сейчас здесь ранний **интерактивный прототип главной**, не готовый к запуску: заявки не подключены, часть текстов требует проверки перед публикацией.

## Просмотр

Откройте `site/index.html` или запустите из корня `python3 -m http.server 8000 --directory site` и перейдите на http://localhost:8000. Сборка и зависимости не требуются. Содержимое `site/` можно раздавать любым статическим веб-сервером. Workflow GitHub Pages предусмотрен, но в настройках репозитория источник Pages должен быть выбран как GitHub Actions.

## Состав

- `site/` — демо главной и стили.
- `docs/PRODUCT.md` — цели, архитектура и сценарии.
- `docs/DESIGN.md` — черновая визуальная система и правила развития.
- `design/` — визуальная карта для согласования и описание направления.
- `backend/` — зарезервировано под будущий сервер и бота; кода интеграций пока нет.
- `AGENTS.md` — контекст для нового чата и автоматизированных помощников.

## Дальше

Согласовать структуру и визуальную систему, проверить данные, затем отдельно спроектировать отправку заявок и интеграцию с ботом/1С. Нельзя считать статическую страницу серверным приложением или готовым решением для персональных данных.
